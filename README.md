# Лабораторна робота 3. Масив чи динамічний список

**Студент:** Ярмошик Артем
**Група:** ІПЗ-3/1
**Мова програмування:** C# (.NET 10)

## Структура

```
lab03/
├── lab3-1.cs   # Задача 1. Журнал у зворотному порядку
├── lab3-2.cs   # Задача 2. Підсумки за місяцями
└── lab3-3.cs   # Задача 3. Останні N подій
```

## Як запустити

Потрібен встановлений [.NET SDK 10](https://dotnet.microsoft.com/download). Відкрий термінал у папці `lab03` і виконай потрібну команду.

Задача 1:
```
dotnet run lab3-1.cs
```

Задача 2:
```
dotnet run lab3-2.cs
```

Задача 3:
```
dotnet run lab3-3.cs
```

## Що робить кожна задача

1. **Задача 1** — `List<string>`, елементи додаються лише в кінець, порядок змінюється через `Reverse()` після збору.
2. **Задача 2** — масив `decimal[12]`, номер місяця використовується як індекс, виводяться всі 12 значень.
3. **Задача 3** — кільцевий буфер на 5 елементів: індекс запису збільшується за модулем N, зсувів немає.
